03 / Design principles

Rules that keep AI workflows sane

01 — Control

Reasoning is not authorization

An agent may propose an action, but policy, permissions and schemas decide whether that action can execute.

02 — State

Conversation is not workflow state

Persist explicit state, decisions, checkpoints and versions so a workflow can resume without depending on the chat transcript.

03 — Resilience

Failure is a normal state

Design timeouts, retries, fallbacks, circuit breakers, compensation and recovery before production incidents happen.

04 — Evidence

Every important decision needs evidence

Capture prompts, model versions, tool calls, inputs, outputs, state transitions and evaluation results with correlation IDs.
